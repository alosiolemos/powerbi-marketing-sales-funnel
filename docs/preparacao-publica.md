## Importação

Use somente o conteúdo desta pasta como raiz de um repositório dedicado. O arquivo LEIA-ME-IMPORTACAO.txt explica o envio pelo site do GitHub.

Não inclua a pasta original de Downloads, cache, contatos reais, credenciais ou conexões. O .gitignore oferece proteção no uso via Git; não impede envios manuais pelo navegador.

Não foi criado repositório remoto, commit ou publicação nesta preparação local.
